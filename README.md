# Monesh V — Portfolio Website

A responsive, single-page portfolio made with HTML, CSS, and vanilla JavaScript. It uses a neon violet and cyan cyberpunk visual style and is ready for GitHub Pages without a build step.

## Files

- `index.html` — portfolio site
- `style.css` — responsive theme, layout, and animations
- `script.js` — floating-square particles, mobile navigation, scroll reveals, active section state, and role animation
- `resume.html` — print-ready résumé; select **Print / Save as PDF** in the browser to download a PDF copy
- `profile-photo.jpeg` — profile photo used in the site header, hero, and footer

## Publish with GitHub Pages

1. On GitHub, create a **public** repository named `moneshram.github.io`.
2. Upload the contents of this folder to the repository's root and commit them to the `main` branch.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish the site at `https://moneshram.github.io/`.

The first publish can take a few minutes. The résumé link opens `resume.html`; use its print button and choose **Save as PDF** in the browser dialog.

## Replace the profile photo

Replace `profile-photo.jpeg` with another photo, then update its image paths and favicon link in `index.html` to match the new filename.

## Personal information

The portfolio includes education, project, skill, and certification details from the supplied résumé. It links to LinkedIn and GitHub for contact and intentionally leaves out the résumé's phone number and email address.
